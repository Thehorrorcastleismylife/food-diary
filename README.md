# Food-diary

**Food-diary** — приложение для подсчёта **КБЖУ** и ведения дневника питания.

Приложение позволяет записывать съеденные продукты и отслеживать количество калорий, белков, жиров и углеводов за день. В интерфейсе отображается текущий прогресс по основным нутриентам, а также список приёмов пищи.

Перед началом работы пользователь может настроить свои параметры: пол, уровень активности, текущий вес, рост, возраст и желаемый вес. Эти данные используются для персональной настройки рациона.

Основная особенность проекта — автоматический подсчёт нутриентов с помощью **GigaChat API**. Пользователь может указать название блюда или продукта, после чего приложение получает рассчитанные значения БЖУ.

При этом автоматический подсчёт не является обязательным. Можно самостоятельно записать КБЖУ продукта: для этого необходимо ввести название еды и вручную указать значения белков, жиров и углеводов.


- **автоматический** — данные о нутриентах рассчитываются через AI.
- **ручной** — пользователь самостоятельно вводит значения КБЖУ.

## Структура проекта

Проект состоит из клиентской части на **HTML/CSS/JavaScript** и отдельного Python-скрипта на **Flask**, который нужен для работы api gigachat.

В репозитории находятся отдельные страницы для первоначальной настройки пользователя, основного дневника питания и аккаунта.

AI-сервис предоставляет endpoint `/get-nutrition`, который принимает название блюда или продукта и возвращает значения бжу.

## Локальный запуск

### Установка Docker

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install ca-certificates curl gnupg
```

После этого можно установить Docker по официальной инструкции для вашей версии Ubuntu или Debian.

### Fedora

Для Fedora Docker предоставляет официальный RPM-репозиторий:

```bash
sudo dnf config-manager addrepo --from-repofile https://download.docker.com/linux/fedora/docker-ce.repo
```

Затем установить Docker Engine:

```bash
sudo dnf install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Запустить Docker и добавить его в автозапуск:

```bash
sudo systemctl enable --now docker
```

Проверить установку:

```bash
sudo docker run hello-world
```

Эти команды соответствуют актуальной инструкции Docker для Fedora.

### RHEL

Для **Red Hat Enterprise Linux 8, 9 и 10** используется официальный RPM-репозиторий Docker:

```bash
sudo dnf -y install dnf-plugins-core
sudo dnf config-manager --add-repo https://download.docker.com/linux/rhel/docker-ce.repo
```

Установить Docker:

```bash
sudo dnf install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

Запустить Docker:

```bash
sudo systemctl enable --now docker
```

Проверить установку:

```bash
sudo docker run hello-world
```



### CentOS

Для CentOS Docker также предоставляет отдельную инструкцию и RPM-репозиторий.

После установки пакетов Docker необходимо запустить:

```bash
sudo systemctl enable --now docker
```

Проверить работу:

```bash
sudo docker run hello-world
```





### Windows

Скачать **Docker Desktop** с официального сайта Docker и установить приложение.

После установки запустить Docker Desktop.

## Запуск проекта

После установки Docker перейти в папку с проектом:

```bash
cd food-diary
```

Запустить контейнер:

```bash
docker run --rm -p 5000:5000 -e GIGACHAT_CREDENTIALS="auth-key" nutrition-app
```

Где:

```text
auth-key
```

 ключ авторизации для GigaChat API.

### Запуск без ключа GigaChat

Ключ от GigaChat необязателен для запуска самого приложения:

```bash
docker run --rm -p 5000:5000 nutrition-app
```

В этом случае автоматический расчёт нутриентов через GigaChat работать не будет, однако можно использовать ручной ввод КБЖУ.

## Открытие приложения

После запуска контейнера открыть браузер и перейти по адресу:

```text
http://localhost:5000
```

## Использование

После запуска приложения пользователь проходит первоначальную настройку и указывает основные параметры своего профиля.

Затем открывается основной экран дневника питания. На нём отображаются съеденные продукты, общее количество калорий и прогресс по белкам, жирам и углеводам.

Новый приём пищи можно добавить через соответствующий интерфейс приложения.

При добавлении блюда можно либо воспользоваться автоматическим расчётом нутриентов через GigaChat, либо самостоятельно указать значения КБЖУ.

Параметры пользователя также можно изменить в разделе аккаунта.
